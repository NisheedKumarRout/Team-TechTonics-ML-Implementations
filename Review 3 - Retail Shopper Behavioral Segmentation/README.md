# Review 3: Retail Shopper Behavioral Segmentation

## 📋 Problem Statement
> **"Segment retail shoppers into distinct behavioral clusters using historical transaction data, purchasing frequency, and total monetary spending. Use these groupings to design tailored promotional campaigns and loyalty rewards."**

---

## 🎯 Project Overview
Understanding the diverse purchasing habits of customer cohorts is fundamental to modern retail analytics. Traditional broad-stroke marketing wastes capital on low-intent users while missing opportunities to retain high-value shoppers.

This project implements unsupervised learning techniques to segment retail shoppers into actionable, distinct behavioral clusters based on the classic **RFM (Recency, Frequency, Monetary)** framework, enabling data-driven promotional campaigns and loyalty tier structures.

---

## 🔬 Core Methodology & Machine Learning Techniques

1. **Feature Engineering & Transformation (RFM Paradigm)**:
   - **Recency ($R$)**: Days elapsed since the customer's last recorded purchase.
   - **Frequency ($F$)**: Total distinct transaction orders executed over the observation window.
   - **Monetary Value ($M$)**: Cumulative gross expenditure generated by the customer.
   - **Data Normalization**: Logarithmic transformation $\log(1 + x)$ to compress heavy-tailed monetary and frequency distributions, followed by `StandardScaler` standard normal normalization ($\mu = 0, \sigma = 1$).

2. **Centroid-Based Clustering (K-Means)**:
   - Hard partition clustering minimizing Within-Cluster Sum of Squares (WCSS) / inertia.
   - Distance metric: Euclidean distance in standardized 3D RFM space.
   - Optimal $k$ cluster selection using the **Elbow Method** and **Silhouette Analysis**.

3. **Distribution-Based Clustering (Gaussian Mixture Models - GMM)**:
   - Probabilistic soft clustering modeling data as a mixture of $K$ multivariate Gaussian distributions:
     $$p(\mathbf{x}) = \sum_{k=1}^K \pi_k \mathcal{N}(\mathbf{x} | \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k)$$
   - Expectation-Maximization (EM) iterative parameter estimation:
     - **E-step**: Calculate posterior responsibilities $\gamma_{ik}$ for each customer.
     - **M-step**: Re-estimate mixture weights $\pi_k$, mean vectors $\boldsymbol{\mu}_k$, and covariance matrices $\boldsymbol{\Sigma}_k$.
   - Rigorous model selection using **Bayesian Information Criterion (BIC)** and **Akaike Information Criterion (AIC)**.

4. **Cluster Evaluation & Validation**:
   - **Silhouette Score**: Quantifying intra-cluster cohesion vs. inter-cluster separation.
   - **Davies-Bouldin Index**: Evaluating cluster compactness and similarity.

5. **Business & Promotional Strategy Alignment**:
   - **Champions / High-Value Loyalists**: VIP concierge, exclusive early access, premium rewards.
   - **Potential Loyalists / Steady Regulars**: Upselling, category expansion incentives.
   - **At-Risk / Lapsing Shoppers**: Re-engagement win-back discounts, personalized notifications.
   - **Occasional / Low-Value Shoppers**: Automated promotional blasts, low-touch retention.
